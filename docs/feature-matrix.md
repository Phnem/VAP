## Легенда

**Статус**
- **Готово** — реализация найдена и прочитана в коде. На устройстве не запускалась.
- **Частично** — есть часть функции или близкий аналог в другом контексте (аудиокниги, аниме-коллекция, стриминг).
- **Нет** — поиск по паттернам из `audit.md` §6 ничего не нашёл.
- **Не проверено** — признаки есть, но код не читался достаточно глубоко.

Если в реализации нет явной пометки Эn/VAP, статус относится к найденной реализации Vetro. Сводка не означает, что все эти функции уже перенесены в VAP: готовность этапов VAP — в `plan.md`.

**Перенос:** *Копировать* = перенести файл как есть с заменой пакета; *Адаптировать* = перенести и изменить; *Заново* = в Vetro нет подходящей основы.

**Приоритет** = номер этапа, на котором функция реализуется в VAP. `Э3` = нужна уже для первой рабочей сборки.

**Сокращения путей** (все под `app/src/main/java/com/example/myapplication/`):
`LP` = `localplayer/ui`, `LPD` = `localplayer/domain`, `MU` = `media/ui`, `MP` = `media/player`, `MS` = `media/subtitles`, `WH` = `media/subtitles/whisper`, `MR` = `media/remote`, `SRC` = `media/source`, `AB` = `audiobooks`, `UIS` = `ui/shared`.
