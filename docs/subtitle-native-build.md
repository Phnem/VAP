# Нативный backend субтитров

VAP использует libass 0.17.5 (ISC), FreeType 2.15.0 (вариант FreeType License), HarfBuzz 13.0.1 (лицензии из COPYING) и динамическую FriBidi 1.0.17 (LGPL). Полные уведомления включены в APK в assets/licenses. Лицензия собственного кода VAP остаётся MIT. Это отдельные библиотеки, их код не переписывается под MIT.

`tools/build-subtitle-native.py` собирает библиотеки из исходников для arm64-v8a, armeabi-v7a, x86_64 и x86. libass закреплён архивом тега и SHA256; версии/хэши остальных архивов находятся в `tools/native/wraps`. Скрипт вызывается задачей Gradle prepareSubtitleNative до CMake. Требуются Python 3.12+, NDK 27.0.12077973, CMake 3.22.1 и C-компилятор компьютера для генераторов Unicode FriBidi. В Windows Meson находит установленный MSVC Build Tools; в Linux нужен системный компилятор.

Используются Meson 1.6.1 и Ninja 1.11.1.3 в отдельном venv внутри app/build. Первая сборка скачивает исходники; повторная использует локальный кэш. Для сборочной инфраструктуры без сети исходные архивы нужно подготовить заранее, включая packagecache Meson. ARM ASM, необязательные приложения/тесты, Fontconfig, DirectWrite, CoreText, libunibreak и дополнительные библиотеки subsetting/raster/vector HarfBuzz отключены. Рендер шрифтов выполняет FreeType, shaping — HarfBuzz.

Исправление сборки FriBidi: в `gen.tab/meson.build` проверка заголовков для генераторов использует `meson.get_compiler('c', native: true)`. Без этого при cross-build на Windows Android-проверка strings.h ошибочно попадала в параметры MSVC. Это единственная локальная правка зависимости; её точное преобразование находится в скрипте.

JNI-код VAP — `app/src/main/cpp/ass_jni.c`. FriBidi остаётся отдельной libfribidi.so, без встраивания её кода в JNI. Изменённые исходники воспроизводимы архивами и скриптом; можно заменить динамические библиотеки и пересобрать/переподписать APK. Для релизного распространения исходные архивы, сборочные инструкции и скрипты должны публиковаться вместе с соответствующей версией APK; метаданные F-Droid относятся к этапу 10.

Каждая собираемая библиотека получает max-page-size=16384. Проверка ELF и упаковки APK выполняется отдельно; наличие флага не заменяет проверку на устройстве с 16-КБ страницами. Исходные ASS-файлы копируются в приватное хранилище без преобразования; нормализованный текст хранится отдельно для поиска, редактирования и экспорта.

Первичные источники: [libass COPYING](https://github.com/libass/libass/blob/0.17.5/COPYING), [сборочная конфигурация libass](https://github.com/libass/libass/blob/0.17.5/meson.build), [API libass](https://github.com/libass/libass/blob/0.17.5/libass/ass.h). Версии и контрольные суммы FreeType/FriBidi/HarfBuzz закреплены файлами WrapDB в репозитории.
