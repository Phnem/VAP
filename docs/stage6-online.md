# Онлайн-субтитры — 6.4

Состояние на 2026-10-21: код реализован; контракт и интерфейс проверены на Xiaomi 13 / Android 16. Настоящий ключ OpenSubtitles не предоставлен, живые поиск, учётная запись и квота сервиса остаются непроверенными.

## Возможности

В плеере: «Субтитры → Онлайн». Поиск по названию, сезону/серии, языкам и moviehash (сумма размера и первых/последних 64 KiB). Хеш недоступного для seek источника заменяется поиском по названию с сообщением. Найденные варианты показывают релиз, точное совпадение, доверенный источник, машинный перевод, SDH и FPS. Предпросмотр загружает файл и расходует квоту; подтверждение подключает приватную копию к текущему видео. Копию можно удалить во вкладке дорожек.

Клиент адаптирован из Vetro `OpenSubtitlesClient` и `ExternalSubtitleService`: контракт запросов, кэш по file_id, обработка квот и ранжирование. Vetro не изменён. В VAP добавлены поиск по хешу, просмотр текста и нативное шифрование без Ktor/DI-графа Vetro.

Ключ задаёт пользователь. Вход в аккаунт необязателен; пароль существует только в памяти формы и запросе входа. Ключ и токен защищены AES-GCM в Android Keystore с привязкой к имени поля; резервное копирование приложения отключено. Заголовки API и токен не передаются на CDN. API-host после входа ограничен официальными api/vip-api; HTTPS обязателен.

Поиск кэшируется на 24 часа (24 записи), загруженные файлы — до 12 записей. Ограничены размер ответа (1 MiB), файл/распаковка (5 MiB), число результатов и перенаправлений. Повтор GET после 429 ограничен одной попыткой; повтор POST загрузки автоматически не выполняется. Отображаются ошибки ключа, сессии, квоты, доступа, сети и неподходящего файла. В базовый APK новые библиотеки не добавлены.

## Проверки

- Debug/release, JVM-тесты и lint проходят. Добавлены 7 JVM-проверок moviehash, canonical query и разрешённых API-host.
- Нативный набор `online` прошёл на подключённом Xiaomi 13: реальный Android Keystore, разные nonce, защита от переноса ciphertext между полями, вход/поиск/429/кэш/загрузка через подставной транспорт, gzip, отказ HTML вместо SRT, отсутствие credentials в CDN-запросе.
- Открыты вкладка «Онлайн» и форма ключа; снимок `app/build/device-test/online-subtitle-account.png` просмотрен.
- Запросы к живому аккаунту не выполнялись. Ответы настоящего сервиса, гостевые ограничения и истечение токена требуют проверки своим ключом; при истечении токена доступен повторный вход.

Основные файлы: `network/CredentialVault.kt`, `network/BoundedHttp.kt`, `player/subtitles/online/*`, `player/ui/OpenSubtitlesPanel.kt`, `OnlineSubtitleDeviceTest.kt`. Интеграция — SubtitleToolsDialog, PlayerScreen, PlaybackSettingsViewModel; строки — EN/RU.

Контракт сверён с [официальным примером OpenSubtitles](https://blog.opensubtitles.com/opensubtitles/how-to-build-a-movie-subtitle-finder-cli-with-python-and-the-opensubtitles-api), опубликованным 2026-10-15. Получить ключ можно в [OpenSubtitles Consumers](https://www.opensubtitles.com/en/consumers).
