# Автоматическая видеотека — 2026-10-20

Первый запуск запрашивает доступ к видео. После выдачи разрешения MediaStore сканируется в фоне по всем доступным shared-storage volumes; ручной выбор корня больше не обязателен. По умолчанию папки отсортированы по количеству видео, по убыванию. В плоском режиме считается собственное содержимое, в дереве — содержимое ветки. Избранное не обгоняет папку с большим количеством видео при этой сортировке.

На Android 13+ запрашивается READ_MEDIA_VIDEO, на Android 14+ также READ_MEDIA_VISUAL_USER_SELECTED для корректного ограниченного доступа; на Android 8–12 — READ_EXTERNAL_STORAGE (maxSdkVersion=32). MANAGE_EXTERNAL_STORAGE не используется. После отказа приложение не повторяет запрос при каждом запуске; доступны кнопка выдачи доступа и SAF. Частичный доступ показывается явно, выбор можно расширить. Фактическое разрешение проверяется при возвращении в приложение; строки MediaStore не сохраняются в дисковый кэш. ContentObserver обновляет библиотеку при добавлении и удалении видео.

SAF остаётся для отдельных папок и неиндексированных файлов. Известные пересечения SAF/MediaStore удаляются по пути/идентификатору. Сканирование не даёт доступа к приватным каталогам других приложений и не обещает найти файлы, исключённые из MediaStore, например через .nomedia.

## Проверки

- Debug, минифицированный release, lint: успешно, ошибок lint нет.
- 58 JVM-тестов: успешно. Восемь новых проверяют группировку, тома, глубокую вложенность, сортировку, плоский/древовидный подсчёт и устранение дублей.
- Xiaomi 13, Android 16/API 36: системный запрос, отказ, повторный холодный запуск без навязчивого запроса, выдача полного доступа, автоматический список.
- Реальный системный выбор одного тестового видео: папка Many содержит ровно 1 доступный файл; результат сохраняется после force-stop. При отзыве доступа старые папки исчезают.
- Нативный набор `library`: папки Many (3) и One (1), поиск, содержимое Many, воспроизведение MediaStore content URI; вставка и удаление тестового видео меняет счётчик 3→4→3 без ручного обновления. Пройден дважды.
- Минифицированный release: автоматический список 3→1, три файла с длительностью/размером кадра, в журнале процесса нет падения или SecurityException. Затем восстановлена debug-сборка.

Тестовые файлы создаёт `tools/prepare-library-fixtures.ps1`; пользовательские файлы скрипт не удаляет. Таймаут экрана телефона не менялся. Физический USB и другие версии Android пока не проверены.

## Правила распространения

Запрос ограничен видео, необходимыми основной функции видеоплеера. Google Play требует обоснования постоянного широкого доступа и декларации; этот код сам по себе не означает одобрение публикации. См. [политику Google Play](https://support.google.com/googleplay/android-developer/answer/16935362?hl=en), [модель MediaStore](https://developer.android.com/training/data-storage/shared/media), [частичный доступ Android 14](https://developer.android.com/about/versions/14/changes/partial-photo-video-access). Для F-Droid остаются требования к свободным зависимостям, сборке и приватности: [Inclusion Policy](https://f-droid.org/en/docs/Inclusion_Policy/).
