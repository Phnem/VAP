# Этап 8.2 — перевод субтитров

Дата: 2026-10-21. Локальный перевод реально выполнен на Xiaomi 13; облако проверяется тестовым транспортом, платные запросы не отправлялись.

## Движок и модели

В Vetro готового перевода субтитров и локального NMT не было: менеджер моделей `manga/translate/TranslationModels.kt` обслуживает OCR, а не перевод. Проверены его pinned-spec подход и контракт TranslationResponse с идентификаторами фрагментов. В VAP повторно используются CredentialVault, BoundedHttp, SubtitleStorage и общий foreground runtime. Загрузка файлов моделей выделена из WhisperModels в `ai/models/ModelFiles.kt`: размеры, свободное место, Range, SHA-256, отмена и частичные файлы общие для Whisper и NMT.

CTranslate2 v4.8.3 (`8d91aa08225004755360daa43deb62b35b1ed65d`) и SentencePiece v0.2.1 (`31646a467d2051eb904e0b45de3a73e91fe1c1e3`). Последняя выбрана с встроенным минимальным absl/protobuf, без скрытых git-загрузок на этапе CMake. `tools/prepare-translation-source.py` закрепляет SHA-256 всех архивов и CPU-зависимостей spdlog, ruy, cpu_features, cpuinfo. Никакой сборки из текущей папки Vetro.

CPU/Ruy int8, два потока, без MKL, CUDA, OpenMP и proprietary SDK. Четыре ABI. Для Android отключён неподдерживаемый pthread_setaffinity_np; CTranslate2 принудительно получает PIC после upstream unset. На ARM32 элементные операции используют generic kernels, потому что upstream NEON Vec/CpuIsa определены для ARM64. Патч affinity воспроизводится скриптом; остальные настройки находятся в CMake. Собираются только vap_ass/vap_whisper/vap_translation, не CLI SentencePiece.

Отдельные модели EN→RU и RU→EN, по **82 459 917 байт** каждая, не входят в APK. Это int8-конверсия Helsinki-NLP OPUS-MT под Apache-2.0 из `manancode/opus-mt-{en-ru,ru-en}-ctranslate2-android`. HF revisions: `8693481face72247976d2a7da8610ed4c75d9e83`, `9f66440658d009510d9e670ae813c7452fd38234`. Полные URL, размеры и SHA-256 пяти файлов каждой модели сохранены в `assets/models/translation-models.json`. Есть явные загрузка/удаление, размер/занятое место, проверка файлов. Для загрузки используются общие границы/проверки ModelFiles. Перед вычислением — не менее 500 МБ доступной RAM и отсутствие lowMemory.

## Пользовательский сценарий

Плеер → Субтитры → Перевод. Выбор исходной импортированной/извлечённой/Whisper дорожки, языков, локального или облачного режима. При повторном открытии после перевода выбирается исходная дорожка из secondary, а не автоматически уже переведённый текст; язык берётся из метаданных выбранной дорожки. Локальные пары EN/RU доступны без Google SDK и сети после загрузки моделей.

Перевод создаётся отдельной дорожкой; оригинальные реплики и таймкоды не меняются. При включённом параллельном показе перевод становится основной дорожкой, оригинал — второй. Обе можно выбрать/редактировать/экспортировать через существующие «Дорожки»/«Текст» в SRT/VTT. Предусмотрена обычная нормализация пробелов, регистра первого символа и конечной пунктуации; это не универсальная проверка грамматики.

Глоссарий: до 64 пар оригинал=перевод. В локальном режиме найденные термины вставляются буквально между переведёнными фрагментами, с границами слов и предпочтением длинного термина. Имена получаются одинаковыми, но раздельный перевод соседних фрагментов может ухудшать согласование/падежи; это указано в UI. Unicode-фрагменты до 200 code points не разрывают surrogate pairs.

Локальная модель загружается один раз на задачу. Работа идёт пакетами по 16 исходных реплик, готовые пакеты атомарно кэшируются. Ключ учитывает исходный текст, языки, backend/model, глоссарий и флаги обработки; API-ключ в него не входит. Кэш ограничен как Whisper: 40 000 реплик, 8 МБ на запись, 64 МБ совокупно; есть очистка. После отмены повторный запуск пропускает готовые пакеты и не дублирует итоговую дорожку.

## Облачный режим

Настраивается HTTPS `/chat/completions` endpoint, ID модели и собственный Bearer API-ключ. Пример URL — OpenRouter; модель/ключ не подставляются автоматически. Настройки секретов сохраняются CredentialVault/Android Keystore, ключ маскируется и не попадает в saved-instance state, URI или кэш. Сохранённые данные можно удалить.

Кнопка «Отправить текст и перевести» отправляет только выбранные тексты; аудио не передаётся. Нет автоматического перехода с локальной модели на облако и автоматических повторов POST. Провайдер может взимать оплату. Один запрос: до 16 реплик / 24 000 символов, JSON тела ≤128 КБ, ответ ≤1 МБ. Redirect запрещён общим PlatformHttp; ключ остаётся на введённом origin. Ответ проверяется по целочисленным уникальным ID, количеству/границам текста, finish_reason; таймкоды берутся из оригинала, а не ответа модели.

Глоссарий и отдельный флаг исправления ошибок распознавания входят в инструкцию облачной модели. Можно исправлять текст на том же языке. Точность перевода и смыслового исправления зависит от модели; настоящие провайдеры и биллинг без пользовательского ключа не проверены. Ни ключ, ни текст из ответа с ошибкой JSON не выводятся как диагностический дамп.

## Фон и отмена

Общий AiRuntime сериализует Whisper, загрузки и перевод. AiProcessingService использует mediaProcessing/dataSync, уведомление, отмену и timeout. `NativeWork` ждёт фактического завершения нативного finally после abort, прежде чем помечать задание завершённым. Контекст/модель освобождаются после задачи. Callback CT2 не владеет контекстом, чтобы уничтожение Translator не могло произойти на собственном CT2 worker; join выполняется вне mutex реестра. Изменение общей подсистемы повторно проверено набором Whisper.
