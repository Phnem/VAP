# VAP v0.6-Stable — Vetro Android Player

Pinch zoom that never drags the picture, and new episodes that show up right away.

## What's new

- **Fix: zoom no longer moves the picture.** A pinch only scales the picture around the centre of the screen. In a zoomed video one finger keeps its normal job: brightness, volume, seeking and hold-to-speed all work.
- **Fix: new episodes show up right away.** Files that another app wrote but the system has not indexed yet are found in the folders VAP already knows and added to the library in the background.
