# VAP v0.4-Stable — Vetro Android Player

Tracks what is new, selects several videos at once, and closes folders reliably.

## What's new

- **New videos and folders rise to the top.** Anything you have not opened yet gets an orange *New* chip. A folder shows the chip when the folder itself or all of its videos are new, and a small dot when only some videos inside are. Everything already on your device at the first scan is not flagged.
- **Multi-select by long press.** Hold a video, tap more, and a glass mini-dock offers delete (always with confirmation), move to another folder, favorite, and mark as watched. *Move* parks a square stack of thumbnails in the top-left corner while you browse to the target folder; confirm flies them into its grid, cancel throws them off the screen.
- **Results in a glass pill** above the dock instead of a system toast.
- **Fix:** closing a folder no longer skips the flying sheets after a rotation, a theme change, or when the folder was scrolled.

Requires **Android 8.0+**. Both APKs use the same release signing key. Package ID: `com.phnem.vap`. Version: `v0.4-Stable`. Version code: `5`. Updating from `v0.3-Stable` preserves app data; the library database is upgraded in place. Deleting and moving videos asks for the system's consent on Android 11 and later.
