🎬 VAP v0.5-Stable

What's new:
• Fixed the frozen or missing picture: some videos showed a still frame while the sound kept going, mostly after returning from the mini window
• Fixed picture-in-picture: no more second, black window, and the system window keeps its picture when you leave the app
• The PiP button now puts the video in the system window and takes you to the home screen
• The top button is a folder with an arrow: back to the library, playback continues in the mini window
• Removed the "Continue watching?" prompt when the library opens
• A video opened from a file manager shows its name instead of a number
