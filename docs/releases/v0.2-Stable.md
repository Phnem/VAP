# VAP v0.2-Stable — Vetro Android Player

VAP now updates itself, minimizes into a floating mini player, and has a lighter, calmer library.

## What's new

- **In-app updates.** VAP finds new releases on GitHub, downloads them over several parallel connections, checks the file size, SHA-256, and signing key, and opens the system installer.
- **Mini player.** The arrow in the player minimizes it into a small draggable window over the library. Playback keeps going; tap to expand.
- **Speed ruler.** 0.5×–3.0× in 0.05× steps, with 0.8×, 1×, 1.25×, 1.5×, and 2× presets.
- **Orientation by video.** Vertical videos open in portrait, everything else in landscape.
- **Flat colored folders** instead of frosted glass: lighter on the GPU, nicer to scroll. Folders open and close, with the sheets flying in and out, in grid, list, and tree modes.
- **Animated grid ↔ list switching** and spring selectors for filters, language, and theme.
- **Smarter search:** `911` and `9.1.1` find `9-1-1`.
- **Pull to refresh** on the library and inside a folder.
- **Settings:** language, theme, update check, and AI model downloads.
- **Fix:** Back from the player no longer closes the whole app.

Requires **Android 8.0+**. Both APKs use the same release signing key. Package ID: `com.phnem.vap`. Version: `v0.2-Stable`. Version code: `3`. Updating from `v0.1-Stable` preserves app data. Android asks once to allow VAP to install apps before the first in-app update.
