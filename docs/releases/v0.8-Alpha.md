# VAP v0.8-Alpha — Vetro Android Player

A pre-release with a new gesture: pinch to leave a folder.

## What's new

- **Pinch to close a folder.** Pinch two fingers together inside an open folder and it folds up with your fingers: the sheets fly back to the folder card and the screen shrinks toward it. Let go past about a fifth of the way, or with a quick pinch, and it closes; let go sooner and it springs back open. In a nested folder (tree mode) a pinch goes up one level when you let go.

## Alpha notes

- The in-app updater never offers Alpha builds. Install this one by hand; later Stable builds update normally.
- Not included yet: the zoom of the home screen from the design reference and an on-screen hint.
