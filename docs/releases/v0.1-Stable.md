# VAP v0.1-Stable — Vetro Android Player

Meet the newest member of the Vetro family: the player from Vetro Collection is now available as a standalone Android app.

## In this release

- A dedicated video library with folder previews, search, favorites, playlists, and resume playback.
- Media3 playback with gesture controls, track selection, and picture-in-picture.
- Styled ASS/SSA and dual subtitles, editing, synchronization, and export.
- Network sources, Jellyfin, Emby, Plex, and DLNA.
- Whisper subtitle generation, local EN/RU translation, and Smart Sync. Models are downloaded separately; local tools work offline once the models are installed.
- The familiar Vetro interface with glass panels, animations, and light and dark themes; English and Russian UI languages.

## Choose your download

| File | Purpose |
| --- | --- |
| `VAP-v0.1-Stable-foss.apk` | Main build without the Google Cast SDK; includes DLNA |
| `VAP-v0.1-Stable-cast.apk` | Adds Google Cast support |
| `VAP-v0.1-Stable-native-sources.zip` | Pinned native dependency sources and build scripts |
| `SHA256SUMS.txt` | Checksums for release files |

Requires **Android 8.0+**. Both APKs use the same release signing key and include `arm64-v8a`, `armeabi-v7a`, `x86_64`, and `x86`. Package ID: `com.phnem.vap`. Version: `v0.1-Stable`. Version code: `2`. The variants replace each other; updating an installation signed with the same key preserves app data.

## Validation

Both release APKs were built with R8 and resource shrinking. All 147 JVM tests passed for each variant, for 294 successful test executions. Android lint reported 0 errors: FOSS had 77 warnings and 1 hint; Cast had 78 warnings and 1 hint.

Checks covered APK signatures, version metadata, all four ABIs, Cast SDK inclusion only in the `cast` variant, APK packaging alignment, and 16 KB ELF segment alignment for 64-bit libraries. Instrumentation tests were not rerun on a device for this publication; reports from earlier development stages are in `docs/`.

Codec and TV receiver compatibility depend on the device. Universal transcoding and streaming live subtitles are not implemented. See the [README](https://github.com/Phnem/VAP#readme) for other limitations and instructions.
