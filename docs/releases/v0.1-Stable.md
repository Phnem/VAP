# VAP v0.1-Stable — Vetro Android Player

Встречайте нового участника семейства Vetro: плеер из Vetro Collection теперь доступен как отдельное Android-приложение.

## В этом релизе

- Собственная видеобиблиотека: папки с превью, поиск, избранное, плейлисты и продолжение просмотра.
- Плеер на Media3 с управлением жестами, выбором дорожек и режимом «картинка в картинке».
- Стилизованные ASS/SSA и двойные субтитры, редактирование, синхронизация и экспорт.
- Сетевые источники, Jellyfin, Emby, Plex и DLNA.
- Whisper для создания субтитров, локальный перевод EN/RU и Smart Sync. Модели загружаются отдельно; после загрузки локальные инструменты работают без сети.
- Знакомый интерфейс Vetro со стеклянными панелями, анимациями, светлой и тёмной темами; русский и английский языки.

## Какой файл скачать

| Файл | Назначение |
| --- | --- |
| `VAP-v0.1-Stable-foss.apk` | Основной вариант без Google Cast SDK, с DLNA |
| `VAP-v0.1-Stable-cast.apk` | Вариант с дополнительной поддержкой Google Cast |
| `VAP-v0.1-Stable-native-sources.zip` | Закреплённые исходники нативных библиотек и скрипты их сборки |
| `SHA256SUMS.txt` | Контрольные суммы файлов релиза |

Требуется **Android 8.0+**. Оба APK подписаны одним релизным ключом, включают `arm64-v8a`, `armeabi-v7a`, `x86_64` и `x86`. Package ID — `com.phnem.vap`, версия — `v0.1-Stable`, versionCode — `2`. Варианты заменяют друг друга; обновление поверх сборки с той же подписью сохраняет данные.

## Проверки

Оба release APK собраны с R8 и сокращением ресурсов. Выполнены 147 JVM-тестов для каждого варианта — все 294 прошли. Android lint: 0 ошибок; FOSS — 77 предупреждений и 1 подсказка, Cast — 78 предупреждений и 1 подсказка.

Проверены подписи APK, метаданные версии, четыре ABI, наличие Cast SDK только в варианте `cast`, выравнивание упаковки APK и ELF-сегментов 64-битных библиотек для 16-КБ страниц. Новый прогон инструментальных тестов на устройстве для этой публикации не выполнялся; подробные результаты предыдущих этапов находятся в `docs/`.

Поддержка кодеков и ТВ-приёмников зависит от устройства; универсальное транскодирование и потоковые live-субтитры не реализованы. Остальные ограничения и инструкции — в [README](https://github.com/Phnem/VAP#readme).
