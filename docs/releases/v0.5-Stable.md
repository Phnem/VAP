# VAP v0.5-Stable — Vetro Android Player

Picture-in-picture that works, no more frozen picture, and no resume prompt.

## What's new

- **Fix: frozen or missing picture.** Some videos opened with a still frame or no picture while the sound kept going, most often after returning from the mini window to the player. The picture is now handed between the player and the mini window explicitly.
- **Fix: two PiP windows, one black.** The *PiP* button no longer opens the library mini window next to a black system window, and the system window keeps its picture when you leave the app.
- **PiP goes to the home screen.** The *PiP* button puts the video in the system window and takes you to the home screen.
- **Folder button with an arrow** at the top of the player: back to the library, playback continues in the mini window.
- **No "Continue watching?" prompt** when the library opens. The last session still waits in the mini window.
- **Fix:** a video opened from a file manager shows its name instead of a number.
