# VAP v0.7-Stable — Vetro Android Player

The Vetro mascot moves into VAP: empty screens and errors now have a character instead of a grey line of text.

## What's new

- **The mascot in empty states.** The animated Vetro mascot, taken from Vetro Collection, shows up on first launch (waving, with a heart), in a search with no results (looking through a magnifier), in empty folders, filters, playlists and the queue (an open empty box), while VAP looks for Cast devices (magnifier), in an empty network folder (empty box) and when a file cannot be played (a question mark over its head).
- **Calm when asked.** With the system setting *Remove animations* the mascot stands still in an expressive pose. It follows the light and dark themes of the app and of the player panels.

## Changed

- The first-launch screen without folders shows the mascot instead of the VAP wordmark.
